# Java-Lesson ☕

Welcome to the **Java-Lesson** repository! This project is a structured collection of beginner-friendly Java programming lessons and exercises covering fundamental concepts, from basic syntax to control flow and loops.

## 📖 About This Repository
This repository serves as a step-by-step learning resource for mastering the fundamentals of Java programming. It is broken down into sequential modules that introduce core concepts, making it ideal for university students building a strong foundation in software engineering, or anyone looking to review the building blocks of Java.

## 📂 Folder Structure & Topics Covered

The repository is organized into numbered folders, each focusing on a specific Java concept. You can navigate directly to the source code for each topic:

* **[01. Print String](./01.%20Print%20String)** - Basics of outputting text to the console.
* **[02. Operator Precedence](./02.%20Operator%20Precedence)** - Understanding the order of operations in Java.
* **[03. Escape Sequences](./03.%20Escape%20Sequences)** - Using special characters (like `\n`, `\t`) in strings.
* **[04. Data Types & Variable Naming](./04.%20Data%20Types%20%26%20Variable%20Naming)** - Core data types (`int`, `String`, `double`, etc.) and naming conventions.
* **[05. Relational operators & Logical operators](./05.%20Relational%20operators%20%26%20Logical%20operators)** - Evaluating conditions and boolean logic (`&&`, `||`, `!`).
* **[06. Assignment Operator & Increment Decrement](./06.%20Assignment%20Operator%20%26%20Increment%20Decrement)** - Modifying variable values efficiently (`+=`, `++`, `--`).
* **[07. User Input](./07.%20User%20Input)** - Capturing input from the user via the `Scanner` class.
* **[08. Selection](./08.%20Selection)** - Control flow using `if`, `else if`, and `else` statements.
* **[09. Switch Case Statement](./09.%20Switch%20Case%20Statement)** - Alternative control flow for discrete values.
* **[10. While Loop](./10.%20While%20Loop)** - Iterating based on a condition.
* **[11. Do While Loop](./11.%20Do%20While%20Loop)** - Ensuring at least one iteration of a conditional loop.
* **[12. For Loop](./12.%20For%20Loop)** - Standard iteration loops for arrays and ranges.
* **[13. Break, Continue and Return Statements](./13.%20Break%2C%20Continue%20and%20Return%20Statements)** - Managing and altering loop and method execution flows.

## 🚀 Getting Started

To get started with these lessons, clone the repository to your local machine:

```bash
git clone https://github.com/Chenitha-Vindiya/Java-Lesson.git

```

You can open the project in your favorite Java IDE (such as IntelliJ IDEA, Eclipse, or VS Code) and run the individual examples to see how they work.
